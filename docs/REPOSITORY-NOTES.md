- 목록·언어·스타·갱신일은 실행 시 GitHub API의 실제 값입니다.
- 이름만으로 기능을 추정하지 않고 README와 소스를 함께 참고했습니다.
- `boost-wiz-frontend`는 기본 Next.js 화면이므로 초기 구성으로 소개했습니다.
- `TokitOnboarding`은 과제 안내와 목 서버가 중심이므로 완성 서비스로 소개하지 않았습니다.
- `React-MiniBlog`은 라우트의 잘못된 import가 있어 완성 서비스가 아닌 학습 예제로 표현했습니다.
- 새 저장소는 자동 표시되지만 코드 분석과 한국어 설명 작성은 자동 실행되지 않습니다.
