# 검증 기록

검증일: 2026-09-19. 제작 환경의 Chrome에서 확인한 결과입니다. 실제 사용자 계정의 GitHub Pages 배포는 수행하지 않았습니다.

## 기능 검증

| 확인 항목 | 방법 | 결과 |
| --- | --- | --- |
| 실제 GitHub API | 공개 API를 호출하는 원본 페이지에서 확인 | 실제 저장소 45개 렌더링 |
| 이미지 | 프로필 이미지 로드 상태 확인 | 정상 |
| 테마 전환 | 버튼 클릭 | 라이트·다크 변경 |
| 테마 지속 | 전환 후 새로고침 | 선택 유지 |
| 필수값 | 빈 폼 제출 | 세 필드의 오류 안내 |
| 이메일 | 잘못된 형식 입력 | 형식 오류 안내 |
| 정상 제출 | 유효한 이름·이메일·메시지 입력 | 입력 확인 성공, 실제 전송 없음 |
| 메뉴 토글 | 모바일에서 두 번 클릭 | 열림·닫힘과 aria-expanded 일치 |
| 메뉴 키보드 | 열린 메뉴에서 Escape | 닫힘 |
| 메뉴 이동 | 열린 메뉴에서 About 클릭 | 섹션 이동 후 닫힘 |
| 스크롤 UI | 아래쪽 섹션 이동과 맨 위 버튼 | 헤더 배경·버튼 표시·맨 위 이동 |
| 로딩 UI | 응답을 대기시키는 테스트 | 로딩 표시, aria-busy=true |
| 빈 상태 | 테스트 응답 `[]` | 빈 프로젝트 메시지 |
| 요청 제한 | 테스트 응답 HTTP 403 | 제한 안내와 재시도 버튼 |
| 서버 오류 | 테스트 응답 HTTP 500 | HTTP 오류 안내 |
| 재시도 복구 | 첫 요청 500, 재시도 시 실제 목록의 검증용 복사본 | 카드 45개 복구 |
| 타임아웃 | 15초 동안 응답 대기 | 시간 초과 안내와 재시도 |
| 외부 문자열 | HTML 태그가 포함된 테스트 description | 텍스트로 표시, 이미지 태그가 생성되지 않음 |
| Pages 하위 경로 | `/portfolio/` 아래에서 상대 자산 경로 확인 | CSS·JS·이미지·카드 정상 |

실패·빈 상태를 검증할 때는 **별도의 제작용 서버에서만 API 응답을 교체**했습니다. 그 테스트 서버·응답 교체 코드·테스트 화면은 ZIP과 배포용 코드에 들어 있지 않습니다. 원본 페이지는 항상 GitHub API를 요청하며, 실패하면 에러 상태를 표시합니다.

## 반응형 검증

Chrome의 독립 iframe 뷰포트 크기를 변경해 실제 CSS 미디어 쿼리와 DOM 너비를 확인했습니다. 물리적인 모바일 기기·4K 모니터에서 직접 확인한 결과는 아닙니다. 세로 스크롤바가 있는 환경에서는 실제 콘텐츠 너비가 아래 뷰포트 폭보다 약간 작습니다.

| 뷰포트 폭 | 메뉴 | Projects 열 수 | 가로 넘침 |
| --- | --- | --- | --- |
| 320px | 햄버거 | 1 | 없음 |
| 390px | 햄버거 | 1 | 없음 |
| 768px | 가로 메뉴 | 2 | 없음 |
| 1024px | 가로 메뉴 | 2 | 없음 |
| 1440px | 가로 메뉴 | 3 | 없음 |
| 2560px | 가로 메뉴 | 4 | 없음 |
| 3840px | 가로 메뉴 | 4 | 없음 |

Grid 열 수는 실제 사용 가능 폭과 카드 최소 폭에 따라 결정됩니다. 1024px에서 두 열인 것도 의도된 반응형 결과입니다.

## 최종 배포 후 남은 확인

사용자가 Pages를 배포한 뒤, **실제 공개 URL**에서 위 핵심 기능을 한 번 더 확인해야 미션의 배포 항목까지 완료됩니다. 로컬 실행과 공개 배포 성공을 동일하게 취급하지 않았습니다.
